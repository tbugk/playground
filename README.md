# 💰 复利模拟器

> 一个写给自己的小工具：亲眼看看"时间 × 收益率"到底有多大威力。

**在线使用：[tbugk.github.io/playground](https://tbugk.github.io/playground/)** —— 打开即用，无需安装。

## ✨ 功能

- **基础复利计算**：初始资金 + 每月定投 + 年化收益率，算到任意年龄
- **增长曲线图**：账户总值与累计本金双线对照，两线张开的"嘴"就是复利发力的拐点
- **起步时间代价**：一键对比晚 5 年 / 晚 10 年开始的最终差距，拖延的成本一目了然
- **逐年明细表**：每一年的本金与资产，见证复利后期的"垂直起飞"

## 🎯 为什么做这个

17 岁的时候我算了一笔账：每月 300 元、年化 7%，从 17 岁存到 60 岁约 108 万，而 22 岁才开始只剩 75 万——**晚 5 年，少赚 33 万**。

数字不直观，所以写了这个模拟器。现在它替我提醒每一个打开它的人：开始的最好时间是十年前，其次是现在。

## 🛠️ 技术实现

- 纯原生 **HTML + CSS + JavaScript**，单文件，零依赖
- 复利公式按月复利计算：`total = total × (1 + r/12) + monthly`
- 曲线图用原生 **SVG** 绘制，无图表库
- 部署：GitHub Pages 自动构建，push 即上线
